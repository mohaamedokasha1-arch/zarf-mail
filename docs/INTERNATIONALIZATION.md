# 🌐 نظام اللغات (i18n) في ظرف

ظرف يدعم **12 لغة** بتبديل فوري — **بدون إعادة تحميل الصفحة** — مع قلب اتجاه
الصفحة تلقائياً (`dir="rtl"` للعربية والفارسية، و`dir="ltr"` لبقية اللغات).

## 2) الملفات

| الملف | الدور |
|---|---|
| `public/assets/js/boot.js` | يُحمَّل في `<head>`: يضبط `lang` + `dir` + الوضع الليلي **قبل أول رسم** (يمنع أي وميض). مستقل تماماً ولا يعتمد على شيء |
| `public/assets/js/i18n.js` | محرك الترجمة بالكامل (القواميس + المنطق) — **يجب أن يُحمّل قبل `app.js`** |
| `public/index.html` | كل نص ثابت يحمل سمة `data-i18n…` + زر القائمة المنسدلة في الهيدر |
| `public/assets/js/app.js` | النصوص الديناميكية (العدّاد، الإشعارات، المودالات، صفوف الرسائل) عبر `t()` / `tCount()` |

```html
<!-- في <head>: يمنع وميض الاتجاه الخطأ -->
<script src="assets/js/boot.js"></script>

<!-- في نهاية <body>: المحرك ثم منطق الواجهة -->
<script src="assets/js/i18n.js"></script>
<script src="assets/js/app.js"></script>
```

> **لماذا ملف خارجي بدل سكربت مضمّن؟** سياسة CSP تسمح بـ `scriptSrc: 'self'` فقط،
> لذا أي سكربت داخل `index.html` سيُحجب.`boot.js` يحقق نفس الغرض بدون تعطيل الأمان.

## 3) كيف تُترجم العناصر؟

يمرّ المحرك على المستند مرة واحدة عند كل تغيير لغة ويطبق هذه السمات:

| السمة | الأثر |
|---|---|
| `data-i18n="key"` | `element.textContent = t(key)` |
| `data-i18n-html="key"` | `element.innerHTML = t(key)` (للنصوص التي تحتوي وسمًا) |
| `data-i18n-placeholder="key"` | `placeholder` |
| `data-i18n-title="key"` | `title` (تلميح عند المرور) |
| `data-i18n-aria="key"` | `aria-label` (لقارئات الشاشة) |
| `data-i18n-title-doc="key"` | `document.title` |
| `meta[name="description"]` | يُحدَّث تلقائياً من المفتاح `meta.desc` |

مثال من `index.html`:

```html
<h2 class="text-lg font-bold" data-i18n="inbox.title">صندوق الوارد</h2>
<input id="searchInput" data-i18n-placeholder="inbox.search"
       data-i18n-aria="inbox.search" placeholder="ابحث في الرسائل…" />
```

## 4) الواجهة البرمجية (API) للمحرك

```js
const I = window.ZarfI18n;

I.init();                       // يكتشف اللغة (محفوظة → المتصفح → ar) ويطبقها على المستند
I.t('card.copy');               // → "نسخ"
I.t('ttl.validFor', { days: 7 })// → "صالح لمدة 7 أيام"   (متغيّرات {name})
I.tCount('inbox.count', 0);     // → "لا رسائل"            (صيغ الجمع)
I.tCount('inbox.count', 1);     // → "رسالة واحدة"
I.tCount('inbox.count', 2);     // → "رسالتان"
I.tCount('inbox.count', 5);     // → "5 رسائل"
I.tCount('inbox.count', 15);    // → "15 رسالة"

I.setLocale('en');              // تبديل فوري: lang + dir + localStorage + حدث تغيير
I.getLocale();                  // → "en"
I.getCurrentLang();             // → { code, native, english, flag, dir }
I.LANGS;                        // قائمة اللغات الـ 12
I.onChange((code, lang) => { /* أعد رسم ما تريد */ });
```

### صيغ الجمع
كل لغة تحدد قواعدها الخاصة:
* **العربية**: `zero / one / two / few / many / other` — `لا رسائل · رسالة واحدة · رسالتان · 5 رسائل · 15 رسالة`.
* **الروسية**: `one / few / many` — `1 письмо · 2 письма · 5 писем`.
* **البولندية**: `one / few / many` — `1 wiadomość · 2 wiadomości · 5 wiadomości · 22 wiadomości`.
* **العبرية**: `one / two / other` (مثنى) — `הודעה אחת · שתי הודעות · 5 הודעות`.
* بقية اللغات: `one / other`.

## 5) ترتيب اكتشاف اللغة

1. `localStorage['zarf:locale']` (اختيار المستخدم السابق).
2. لغات المتصفح `navigator.languages`.
3. العربية كافتراضي أخير.

## 6) إتاحة الوصول (A11y) ولوحة المفاتيح

القائمة المنسدلة عنصر `role="listbox"` حقيقي:

| المفتاح | الأثر |
|---|---|
| `Enter` / `Space` / `↓` (على الزر) | يفتح القائمة ويضع المؤشر على اللغة المختارة |
| `↑` / `↓` | تنقّل بين اللغات (دوران كامل) |
| `Home` / `End` | أول / آخر لغة |
| `Esc` | يغلق القائمة ويعيد المؤشر إلى الزر |
| نقرة خارج القائمة | إغلاق تلقائي |

كذلك: `aria-expanded` على الزر، `aria-selected` على الخيار الحالي،
وحلقة تركيز (focus ring) واضحة على الخيارات.

---

## 7) الاتجاه (RTL/LTR)

`setLocale()` يضبط `document.documentElement.lang` و `dir` في نفس اللحظة،
وكل تخطيط الواجهة مبني على **خصائص منطقية** (`start/end`, `ps-*`, `text-start`,
`ms-auto`) ليعمل مقلوبًا بشكل صحيح دونCSS إضافي.
كما يتبع إطار الـ HTML للرسالة (`iframe.srcdoc`) اتجاه الواجهة ويُعاد رسمه عند تغيير اللغة.

## 8) إضافة لغة جديدة

1. أضف اللغة إلى مصفوفة `LANGS` في `public/assets/js/i18n.js`:
   ```js
   { code: 'it', native: 'Italiano', english: 'Italian', flag: '🇮🇹', dir: 'ltr' },
   ```
2. أضف قاموسها الكامل إلى `DICT` بنفس المفاتيح (المحرك يسقط تلقائياً إلى الإنجليزية لأي مفتاح ناقص).
3. أضف رمزها إلى قائمة `LANGS` داخل `public/assets/js/boot.js` (وإلى `RTL` إن كانت RTL).
4. لا حاجة لأي تغيير في `app.js` أو `index.html` — تظهر في القائمة مباشرة.
5. شغّل `npm run test:i18n` — سيُبلغك فوراً عن أي مفتاح ناقص أو متغيّر مختلف.

## 9) الاختبار

```bash
npm run test:ui      # 61 فحصاً على الواجهة داخل jsdom
                     #  (اللغات + الاتجاه + لوحة المفاتيح + boot.js + العدّاد + دورة رسالة حقيقية)
npm run test:i18n    # 36 فحصاً لسلامة القواميس بدون سيرفر
```

`test:i18n` يتحقق من:
* كل لغة تملك **نفس مجموعة المفاتيح** (116 مفتاحاً) — لا ناقص ولا زائد.
* كل مفتاح مستخدم في `index.html` / `app.js` موجود فعلاً في القواميس.
* لا قيم فارغة، والمتغيّرات `{name}` متطابقة بين كل اللغات.
* صيغ الجمع الصحيحة لكل لغة، وبيانات اللغات (رمز/علم/اتجاه) سليمة.
* `boot.js` يعرف نفس قائمة اللغات ونفس لغات RTL.

> `test:ui` يحتاج السيرفر يعمل على المنفذ 3000، و`jsdom` مثبتاً (`npm i`).
